1. Executive Summary

이번 EDA의 핵심 메시지 세 가지

  1. 데이터는 풍부하지만, 추천 가능 영역은 좁다. 분석 대상 67,165 페어 중 98.3%가 낙찰 이력 없는 cold 상태이며, 실질적으로 추천 가능한 품목 풀(공급사 10개 이상 확보)은 전체의 7%(22개 품목)에 불과합니다.
  2. Vendor lock-in이 6개 품목에서 이미 진행 중이다. 상위 1개 업체가 낙찰의 50% 이상을 독점하는 품목이 6개 확인됩니다. 에이치앤텍 1사가 2개 품목 동시 지배. 경쟁 환경 모니터링이 시급합니다.
  3. 5번 API 도입으로 cold pool에 처음 신호가 생겼다. 낙찰 이력이 없어 기존 시스템에서 완전히 배제되던 업체 428곳 중 123곳이 SR 보유 사실이 확인됐습니다. Score v2에서 이들을 후보로 복원해야 합니다.

4-5. 전체 시장 집중도 (HHI)

5건 이상 낙찰 이력이 있는 67개 품목의 평균 HHI(허핀달-허쉬만 지수, 시장 집중도 지표)는 0.170입니다. 이는 전반적으로 시장이 분산돼 있음을 의미하지만, 위 6개 품목은 예외적으로 집중됩니다.

HHI 해석: 0.25 이상 = 고집중(독점 우려), 0.15~0.25 = 중간집중, 0.15 미만 = 경쟁적. 평균 0.170은 중간 범위이나, 품목별 편차가 크므로 개별 품목 모니터링이 필요합니다.

7-2. 발견된 5가지 구조적 문제

문제 1 — 커버리지 1%: 67,165 페어 중 685페어(1.0%)에서만 Score가 계산됩니다. 나머지 99%는 점수 없이 추천 불가 상태입니다.
문제 2 — 차원 중복: supply_stability와 track_record가 모두 "낙찰 건수"를 기반으로 합니다. 두 차원이 사실상 같은 것을 두 번 측정합니다.
문제 3 — SR 분류 거칠음: sr_count가 사실상 0 또는 1 이진값(single SR 보유가 90.7%). 다양성 측정이 불가한 구조입니다.
문제 4 — Vendor lock-in 가산 오류: 단독 수주(낙찰률 99%)를 높은 가격 경쟁력으로 계산합니다. 경쟁 배제 상황의 높은 단가율을 "우수"로 잘못 평가하는 역설이 있습니다.
문제 5 — 빈 차원: risk_free(부정당 제재 여부)와 cluster_fit(지역 적합성)이 stub(빈 껍데기) 상태입니다. 실제 데이터가 연결되지 않았습니다.

8. Score v2 새 설계

이번 EDA를 바탕으로 합의된 5개 차원으로 Score를 재설계합니다. 5번 API에서 새로 확보한 신호 3개가 신규 차원으로 추가됩니다.

repeat_strength
데이터: 1번 API
환경공단 누적 낙찰 건수 + 권역 다양성 가중. 단독 수주는 보정 적용.
bid_activity ⭐ 신규
데이터: 5번 API
입찰만 한 BRN까지 포함. Cold pool에 신호 부여. 428곳 복원.
negotiation_loss ⭐ 신규
데이터: 1번 vs 5번
1순위 자주 탈락하는 업체에 페널티. 협상 실패율 반영.
unmet_demand_item ⭐ 신규
데이터: 5번 유찰 카운트
품목 차원. 자주 유찰 = SR 조건 완화 우선 대상으로 분류.
real_sr_flag
데이터: mart_company_sr
female 제외, 장애·사회만 binary. SR 인증 API 보강 후 신뢰도 향상.
